# Historical Reports

These documents are point-in-time snapshots written while DPAN was being
developed (November 2025). They are kept for reference and are **not**
maintained: test counts, issue lists, "not implemented" notes and readiness
assessments in them describe the code as it was then.

For the current state, see the top-level `README.md` and the guides in
`docs/` (user guide, API reference, CLI guide, neural network guide).

| `DPAN_Capability_Evaluation.md` | Capability gaps and enhancement roadmap |
